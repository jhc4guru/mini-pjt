# S3 고수준 명령 (aws s3)

경로는 위치 인자로 준다(`s3://<BUCKET_1>/prefix/`). 옵션만으로는 대상을 알 수 없으므로 `required`는 비워 둔다.

## ls
- 설명: 버킷 목록 또는 버킷/접두사 안의 객체 조회.
- 키워드: 버킷 목록, 파일 목록, 객체 조회, list bucket
- 예시(버킷 목록): `aws s3 ls`
- 예시(객체): `aws s3 ls s3://<BUCKET_1>/ --recursive --human-readable --summarize`

## presign
- 설명: 객체 임시 다운로드 URL 생성(기본 1시간). 로컬 서명만 하며 S3에 쓰기 작업은 없다.
- 키워드: 임시 링크, 공유 URL, presigned url
- 예시: `aws s3 presign s3://<BUCKET_1>/<NAME_1> --expires-in 3600`
- 주의: 출력 URL에 서명이 들어 있다. 외부에 공유되는 값이므로 로그 보관 시 마스킹한다.

## cp
- 설명: 로컬↔S3, S3↔S3 복사.
- 키워드: 업로드, 다운로드, 파일 복사, copy
- 예시: `aws s3 cp s3://<BUCKET_1>/<NAME_1> s3://<BUCKET_2>/<NAME_1>`
- 예시(접두사 전체): `aws s3 cp s3://<BUCKET_1>/logs/ s3://<BUCKET_2>/logs/ --recursive`
- 주의: 같은 키가 있으면 덮어쓴다. 먼저 `--dryrun`으로 대상을 확인할 수 있다.
- 확인: ls

## mv
- 설명: 이동(복사 후 원본 삭제).
- 키워드: 파일 이동, move
- 예시: `aws s3 mv s3://<BUCKET_1>/<NAME_1> s3://<BUCKET_1>/archive/<NAME_1>`
- 주의: 원본이 삭제된다.
- 확인: ls

## rm
- 설명: 객체 삭제. `--recursive`는 접두사 아래 전체를 지운다.
- 키워드: 파일 삭제, 객체 삭제, 폴더 삭제, remove
- 예시: `aws s3 rm s3://<BUCKET_1>/<NAME_1>`
- 예시(전체): `aws s3 rm s3://<BUCKET_1>/tmp/ --recursive`
- 주의: 되돌릴 수 없다(버저닝이 없으면). `--recursive`는 대상 접두사와 개수를 `--dryrun`으로 먼저 확인하도록 계획에 포함한다.
- 확인: ls

## sync
- 설명: 디렉터리/접두사를 동기화. 변경된 파일만 복사한다.
- 키워드: 동기화, 폴더 업로드, sync
- 예시: `aws s3 sync s3://<BUCKET_1>/data/ s3://<BUCKET_2>/data/`
- 주의: `--delete`를 주면 대상에만 있는 객체를 삭제한다. 가드가 `--delete`를 위험으로 표시하고 `--dryrun` 선행을 요구한다.
- 확인: ls

## mb
- 설명: 버킷 생성(make bucket). 버킷 이름은 전 세계에서 유일해야 한다.
- 키워드: 버킷 생성, 버킷 만들기, make bucket
- 예시: `aws s3 mb s3://<BUCKET_1> --region us-east-1`
- 확인: ls

## rb
- 설명: 버킷 삭제(remove bucket). 비어 있어야 하며, `--force`는 내용물까지 삭제한다.
- 키워드: 버킷 삭제, 버킷 제거
- 예시: `aws s3 rb s3://<BUCKET_1>`
- 주의: `--force`는 모든 객체를 지운다. 가드가 `recursive-delete`로 취급한다.
- 확인: ls
